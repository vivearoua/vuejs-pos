# PhoneStore - Système de Gestion de Magasin de Téléphones

## Description
PhoneStore est un système de gestion de magasin de téléphones qui permet de gérer l'inventaire, les ventes, les réparations et les statistiques d'un magasin de téléphones.

## Fonctionnalités
- 👥 Gestion des utilisateurs (administrateurs et caissiers)
- 📱 Gestion de l'inventaire des téléphones
- 🎮 Gestion des accessoires
- 🔧 Gestion des réparations
- 💰 Gestion des transactions
- 📊 Tableau de bord avec statistiques

- JavaScript/TypeScript/vitejs
- React/Next.js
- TailwindCSS
- JSON pour le stockage des données

## Installation
```bash
# Cloner le projet
git clone https://github.com/vivearoua/vuejs-pos.git

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev:all
```
